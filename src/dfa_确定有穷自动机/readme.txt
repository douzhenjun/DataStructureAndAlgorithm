DFA敏感词过滤器 - README
========================

1. 项目作用
-----------
基于确定性有限自动机(DFA)的多模式字符串匹配算法，用于快速检测文本中是否包含敏感词。
- 时间复杂度：O(N×M)，N为文本长度，M为敏感词平均长度
- 空间复杂度：O(S)，S为所有敏感词的字符总数
- 特点：前缀共享，内存优化；最长匹配原则

2. 核心数据结构
---------------
- transitionMap: Map<Integer, Map<Character, Integer>>
  状态转移表，记录从当前状态输入某个字符后转移到哪个新状态

- finalStateSet: Set<Integer>
  终止状态集合，记录哪些状态ID对应敏感词的结尾

- stateCounter: int
  状态计数器，为每个新状态分配唯一ID（从0开始递增）

3. 构建过程 (build方法)
-----------------------
将敏感词列表编译成DFA状态机：
1. 初始化根节点（状态0）
2. 遍历每个敏感词的每个字符：
   - 如果当前状态下已有该字符的转移路径，复用已有状态
   - 如果不存在，创建新状态（stateCounter++），建立转移关系
3. 将每个敏感词的最后一个字符对应的状态标记为终止状态

示例：
敏感词["冰毒","法轮功"]构建后：
状态0(根)--'冰'-->状态1--'毒'-->状态2(终止)
          --'法'-->状态3--'轮'-->状态4--'功'-->状态5(终止)

4. 匹配过程 (match方法)
-----------------------
1. 从文本的每个位置i启动自动机（currentState=0）
2. 从位置i开始逐个字符输入：
   - 查transitionMap，有转移则进入下一状态，matchLen++
   - 无转移则中断
   - 如果进入终止状态，记录lastMatchLen（用于最长匹配）
3. 若匹配到敏感词，截取text[i, i+lastMatchLen)，计数+1
4. 跳过已匹配部分（i += lastMatchLen - 1），避免重叠检测

5. 使用示例
-----------
List<String> words = Arrays.asList("冰毒", "法轮功");
SensitiveWordDFA.build(words);
Map<String, Integer> result = SensitiveWordDFA.match("文本内容...");
// result: {冰毒=出现次数, 法轮功=出现次数}
